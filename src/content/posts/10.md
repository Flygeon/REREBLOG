## 部署环节

首先Fork这个项目到你的仓库，在config文件夹里可以修改配置

首先打开`config/api.config.js`关键修改这里的内容

```javascript
module.exports = {
  // The clientId and clientSecret are used to authenticate the user with Microsoft Graph API using OAuth. You would
  // not need to change anything here if you can authenticate with your personal Microsoft account with OneDrive International.
  clientId: '6c59f174-eca5-4874-b923-407f97fd69f0',
  obfuscatedClientSecret: 'U2FsdGVkX19t/ItgvXWJqOoTPm65cllQNmBY4KcUGYWTZE7a2b8u3PltXBrFvM3uUHHtVROuB1MUZm7QBTipgw==',

  ......
}
```
clientId和Secret都在[Microsoft Azure App registrations](https://portal.azure.com/#blade/Microsoft_AAD_RegisteredApps/ApplicationsListBlade)获取

参考[作者的说明文档](https://ovi.swo.moe/zh/docs/advanced#%E4%BD%BF%E7%94%A8%E4%BD%A0%E8%87%AA%E5%B7%B1%E7%9A%84-client-id-%E4%B8%8E-secret)

也可以参考https://github.com/iRedScarf/onedrive-index这个项目，但很奇怪我卡在了鉴权这一步

在`config/site.config.js`这里可以修改标题和路径，默认会分享你OneDrive里Public文件夹里的内容

操作好后直接导入到Vercel里，这时候会有报错，因为还没连接后端数据库
![图](https://raw.flygeon.eu.org/Flygeon/Astro/refs/heads/main/image/10-1.webp)

前往 [Vercel Upstash 集成页面](https://vercel.com/integrations/upstash) 点击 Install，绑定你的项目，然后重新部署

不出意外的话你会发现又报错了。。。
![图2](https://raw.flygeon.eu.org/Flygeon/Astro/refs/heads/main/image/10-2.webp)

其实这是Node.js 版本导致的，来到settings ——> Build and Deployment ——> Node.js Version里将版本改到20.x然后在重新部署
![图3](https://raw.flygeon.eu.org/Flygeon/Astro/refs/heads/main/image/10-3.webp)

All done.
