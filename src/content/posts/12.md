如标题所言，我将列出我的一些常用软件予以备忘，主要原因是由于Surface的发热量在Windows下过大，不得已我将把我的电脑主力切到Linux。

## 软件
| 软件类型      | 软件名称                                    | 说明                           |
| --------- | --------------------------------------- | ---------------------------- |
| 浏览器       | Edge，Chrome                             | 主力浏览器，泛用性广，用习惯了数据啥的都在就不想换了（（ |
| 编辑器       | VS Code，Trae                            | 代码编辑主力，接入cli以及MCP挺好用的        |
| 终端        | meatshell                               | rust重构后的final shell          |
| 笔记        | Obsidian                                | 黑曜石太强大了                      |
| 输入法       | Win自带，微信输入法                             | 中文输入                         |
| 截图/录屏/播放器 | Pixin，LocalSend，OBS，VLC，MPC-HC          | 好用，不过截图一般我还是习惯win+shift+s    |
| 音乐相关      | SV，Vocaloid4，X studio，openutau，FLstudio | 这个没什么好说的                     |
| 建模相关      | Blender，mmd，PmxEditor                   | 改模这一块                        |
| 玩机相关      | 搞机助手，刷机匣，爱思助手，FastbootEnhance           | 无需多言                         |
